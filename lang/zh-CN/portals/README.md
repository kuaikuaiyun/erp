# 门户业务翻译文件

门户开始开发具体业务时，应按门户编码在语言目录下创建独立翻译文件，例如：

~~~
lang/zh-CN/finance.php
lang/zh-CN/purchase.php
~~~

如果业务模块通过 `__('assistant.xxx')` 方式调用，文件应位于
`lang/zh-CN/assistant.php`；翻译键的首段必须与文件名一致。

门户业务页面、控制器、服务、模型、校验提示、弹窗和前端脚本中所有面向使用者的文字，
都必须调用该门户的翻译键，不允许直接硬编码。通用门户文字保留在
`lang/zh-CN/portal.php`，不应复制到业务门户文件中。
