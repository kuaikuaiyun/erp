# Portal business views

Create a directory for a portal only when its actual business interface is
implemented. The directory name must match the portal module namespace.

~~~
resources/views/portals/finance/
resources/views/portals/purchase/
resources/views/portals/assistant/
~~~

The reusable portal entry, notice and empty-home views remain in
resources/views/portal/.

## Copy and translations

All user-visible copy in a portal business module must use that portal's
language resource. This includes Blade templates, controllers, services,
models, validation messages, modal copy, and text generated by JavaScript.
Do not add user-facing hard-coded strings to portal business files.

Keep portal-specific copy in `lang/{locale}/{portal}.php`, for example
`lang/zh-CN/assistant.php`. Shared portal copy belongs in `lang/{locale}/portal.php`.
